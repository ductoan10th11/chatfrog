01 · Bài toán

AI thương mại đắt và gửi dữ liệu ra ngoài

Chi phí

Phí dịch vụ AI cộng dồn theo số thành viên sử dụng.

Dữ liệu

Tài liệu và ảnh nội bộ bị gửi sang bên thứ ba.

Giải pháp

Tự host Qwen 3.6 (qua Ollama / llama.cpp) và Qwen Image 2.1 (qua ComfyUI) trên GPU RTX 5090 sẵn có. Chi phí vận hành gần như bằng 0, dữ liệu nằm trong hạ tầng do nhóm kiểm soát.

01 · Bài toán

ChatFrog làm được gì?

Chat

Trả lời stream theo từng token (SSE).

Tạo & edit ảnh

Sinh và chỉnh ảnh PNG bằng Qwen Image.

Đọc tài liệu

AI đọc file PDF, DOCX, TXT, CSV đính kèm.

Tài khoản

Login Google, admin duyệt user.

Input

  • Tài khoản Google, message, custom instructions
  • Ảnh PNG/JPEG/WebP đến 10 MB
  • Tài liệu PDF/DOCX/TXT/CSV đến 20 MB

Output

  • Câu trả lời stream, lịch sử conversation
  • Ảnh PNG do model tạo
  • Stats và health của hệ thống cho admin

Security

  • Cloudflare ẩn IP và tự cấp TLS
  • Container API chỉ listen 127.0.0.1, đi qua Nginx
  • UFW chỉ mở port 22 và 80
  • SSH bằng key, không dùng password
  • Rate limit 10 request/phút cho login
  • Atlas: user riêng, quyền giới hạn, kết nối TLS
02 · Deployment

Sáu bước từ máy trắng đến HTTPS

1

Chuẩn bị VPS

SSH key, Git, Make, Nginx, Node 24, Podman.

ssh-copy-id user@vps
2

Domain và DNS

Trỏ nameserver về Cloudflare, thêm record A bật Proxied.

dig +short chat.naot.me
3

MongoDB Atlas

Cluster M0 Singapore, user riêng, lấy MONGO_URI.

mongodb+srv://…
4

Tailscale

Nối VPS với GPU server, gọi model qua IP riêng.

sudo tailscale up
5

Deploy app

Tạo .env, build container, check healthz, build web.

make up && make build-web
6

Nginx, UFW, HTTPS

Reverse proxy cho /api, mở port 22 và 80, TLS do Cloudflare.

make nginx-link

04 · Kết luận & hướng phát triển

Chạy ổn định, sẵn sàng mở rộng

Kết quả

  • Chạy thật tại chat.naot.me qua HTTPS
  • Kết hợp 6 dịch vụ cloud, chi phí gần như 0 đồng
  • Đủ chức năng chat, tạo ảnh, đọc tài liệu

Hạn chế

  • Chỉ login bằng Google
  • Cloudflare → VPS chạy HTTP (mode Flexible)
  • Model không phản hồi thì báo lỗi, user phải gửi lại

Hướng phát triển

  • Origin Certificate, mode Full (strict)
  • CI/CD, backup DB định kỳ
  • Monitoring với Prometheus, Grafana
